# SubMate 결제 메시지 인식 레퍼런스 가이드

본 문서는 SubMate의 **결제 메시지(SMS, 카드사 앱 푸시, 알림톡, 전자 영수증 OCR) 자동 감지 및 구독 등록 기능**을 테스트하고 검증하기 위한 표준 결제 메시지 레퍼런스 규격서입니다.

---

## 1. 결제 인식 아키텍처 개요

SubMate는 다음 두 가지 채널을 통해 결제 정보를 수집하고 정밀 파싱합니다:

1. **안드로이드 실시간 알림 리스너 (`PaymentNotificationListener` / `PaymentParser.java`)**
   - 안드로이드 `NotificationListenerService`를 통해 카드사 앱, 간편결제, SMS 앱의 노티피케이션을 실시간 감지
   - 키워드 필터링, 상호명 추출, 금액 매칭, 동음이의어 오프라인 매장 배제(Business Suffix), 복합 플랫폼 가격 검증(Price Matcher) 수행
   - 감지 성공 시 딥링크(`submate://quick-add?...`)가 포함된 즉시 등록 푸시 알림 발송
2. **전자 영수증 / SMS 텍스트 붙여넣기 및 OCR 파서 (`api/_lib/receiptParser.js`)**
   - 영수증 스크린샷 OCR 텍스트나 복사한 결제 문자를 정규식 및 서비스 카탈로그와 매칭하여 서비스명, 금액, 플랜, 결제예정일(dueDay), 결제수단 자동 추출

## 3. 주요 카드사 및 페이별 표준 메시지 형식

### (1) 신한카드 (신한 SOL페이 / SMS)
- **앱 푸시 제목**: `[신한카드] 승인` 또는 `[신한카드] 승인안내`
- **메시지 본문 예시**:
  - `09/09 14:20 넷플릭스 17,000원(일시불) 정상승인 카드번호: ****-1234`
  - `홍길동님 일시불 13,500원 가맹점: 티빙 승인일시: 2026.09.09 10:15 카드번호: ****1234`

### (2) KB국민카드 (KB Pay / SMS)
- **앱 푸시 제목**: `[KB Pay] 결제안내` 또는 `[KB국민카드] 승인알림`
- **메시지 본문 예시**:
  - `홍*동님 GOOGLE*YouTube 14,900원 결제완료 (매월 정기결제)`
  - `홍*동님 KB국민카드 ****-1234 일시: 2026.09.09 10:30 금액: 14,900원 가맹점: GOOGLE*YouTube 승인번호: 123456`

### (3) 현대카드 (현대카드 앱 / SMS)
- **앱 푸시 제목**: `현대카드 승인` 또는 `현대카드 해외승인`
- **메시지 본문 예시**:
  - `쿠팡 와우 멤버십 7,890원 일시불 결제완료 (매월 정기결제)`
  - `OPENAI $20.00 승인완료 (정기과금)`

### (4) 삼성카드 (모니모 / SMS)
- **앱 푸시 제목**: `[삼성카드] 승인안내`
- **메시지 본문 예시**:
  - `티빙(TVING) 13,500원 일시불 결제 09/09 10:15 삼성카드(1234)`
  - `디즈니플러스 9,900원 결제완료 삼성카드(5678)`

### (5) 우리카드 (우리WON카드 / SMS)
- **앱 푸시 제목**: `[우리WON카드] 승인알림`
- **메시지 본문 예시**:
  - `디즈니플러스 9,900원 결제완료 우리카드(5678)`
  - `넷플릭스 13,500원 일시불 정상승인 우리(1234)`

### (6) 롯데카드 (디지로카 / SMS)
- **앱 푸시 제목**: `[디지로카] 승인`
- **메시지 본문 예시**:
  - `스포티파이 10,900원 일시불 결제완료 롯데카드`
  - `왓챠 7,900원 결제완료 (정기결제)`

### (7) 카카오페이 / 카카오톡 알림톡
- **패키지**: `com.kakaopay.app` 또는 `com.kakao.talk`
- **제목**: `카카오페이 결제완료`
- **메시지 본문 예시**:
  - `가맹점: 멜론 스트리밍 클럽 / 결제금액: 10,900원 / 매월 자동결제`
  - `가맹점: YouTube Premium / 결제금액: 14,900원 / 정기결제 승인 완료`

### (8) 네이버페이
- **패키지**: `com.nhn.android.search`
- **제목**: `네이버페이` 또는 `네이버페이 결제완료`
- **메시지 본문 예시**:
  - `네이버플러스 멤버십 월간이용권 4,900원 정기결제 완료`
  - `티빙(TVING) 네이버페이 13,500원 자동결제 완료`

### (9) 토스 (Toss)
- **패키지**: `viva.republica.toss`
- **제목**: `토스 결제알림`
- **메시지 본문 예시**:
  - `OPENAI $20.00 해외 승인완료 (토스페이)`
  - `넷플릭스 17,000원 결제되었어요`

### (10) 삼성월렛 (Samsung Wallet / Pay)
- **패키지**: `com.samsung.android.spay`
- **제목**: `[삼성월렛] 결제`
- **메시지 본문 예시**:
  - `밀리의 서재 전자책 정기구독 9,900원 결제완료`
  - `유튜브 프리미엄 14,900원 결제완료 삼성월렛`

## 6. 전자 영수증 및 OCR 텍스트 레퍼런스 (`receiptParser.js`)

앱 내 영수증 OCR 기능(`/api/ocr`) 또는 텍스트 붙여넣기 폼에서 인식되는 정형/비정형 텍스트 규격입니다.

### Case A: 라벨형 신용카드 승인 전표
```text
[신용카드 승인전표]
가맹점명: NETFLIX
이용금액: 17,000원
결제일시: 2026-09-09 15:30
결제수단: 신한카드 9876
```
- **파싱 결과**:
  - `name`: "Netflix" (`serviceId`: "netflix")
  - `amount`: 17000
  - `plan`: "프리미엄"
  - `dueDay`: 9
  - `paymentMethod`: "신한카드 • 9876"

### Case B: 전자 영수증 (다음 결제일 명시형)
```text
주문 영수증
서비스: YouTube Premium
청구 금액: 14,900원
다음 결제일: 2026.10.12
지불 수단: 카카오페이
```
- **파싱 결과**:
  - `name`: "YouTube Premium" (`serviceId`: "youtube")
  - `amount`: 14900
  - `plan`: "개인 멤버십"
  - `dueDay`: 12
  - `paymentMethod`: "카카오페이"

### Case C: 모바일 결제 문자 인라인 형식
```text
13,500원 결제완료 티빙 09/10 네이버페이
```
- **파싱 결과**:
  - `name`: "티빙" (`serviceId`: "tving")
  - `amount`: 13500
  - `plan`: "스탠다드"
  - `dueDay`: 10
  - `paymentMethod`: "네이버페이"

```javascript
import { simulatePaymentDetection } from "./src/lib/paymentCapture.js";
```

### 방법 2. Android ADB를 통한 딥링크 직접 테스트

```bash

  com.submate.app
```
